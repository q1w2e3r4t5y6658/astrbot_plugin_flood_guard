# astrbot_plugin_flood_guard（刷屏守卫）

AstrBot 群刷屏检测与自动禁言插件。群消息频率超过阈值时自动禁言，
**阈值 / 窗口 / 禁言时长 / 播报文案** 都可以在**插件配置页**修改，也可以在 **QQ 群内**用指令对**单个群**单独覆盖。

## 功能

- 滑动时间窗口内的消息计数，达到阈值即触发
- 触发后调用平台禁言接口（aiocqhttp / OneBot v11 的 `set_group_ban`）
- 触发后在群内播报，**文案可自定义**（全局 + 单群）
- 同一用户触发后有冷却，避免反复禁言
- 管理员豁免、用户白名单
- 单群覆盖存于插件 KV，卸载重装不丢（AstrBot 数据目录内）

## 安装

1. 把本仓库放到 AstrBot 的 `data/plugins/astrbot_plugin_flood_guard/`（或在 WebUI 的插件市场/从 URL 安装）。
2. 在 WebUI 插件管理里启用并配置。
3. 机器人在目标群里需要是**管理员**，否则禁言会失败（日志会有提示）。

> 依赖：仅使用 AstrBot 内置能力与 Python 标准库，`requirements.txt` 为空。

## 插件配置页（全局默认）

| 配置项 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 是否启用检测 |
| `window_seconds` | 5 | 统计窗口（秒） |
| `max_messages` | 10 | 窗口内达到多少条触发禁言 |
| `mute_seconds` | 600 | 禁言时长（秒），0 表示只播报不禁言 |
| `cooldown_seconds` | 30 | 同一用户触发后的冷却 |
| `notify` | true | 触发后是否在群里播报 |
| `notify_template` | 见下 | 播报文案模板 |
| `exempt_admins` | true | 管理员豁免 |
| `whitelist` | [] | 免检测用户 ID 列表 |

## 群内指令（单群覆盖）

管理员在群里发送：

| 指令 | 作用 |
|---|---|
| `/刷屏 帮助` | 查看用法 |
| `/刷屏 状态` | 查看本群生效配置 |
| `/刷屏 阈值 <条数>` | 本群阈值 |
| `/刷屏 窗口 <秒>` | 本群统计窗口 |
| `/刷屏 禁言 <秒>` | 本群禁言时长 |
| `/刷屏 提示 <文案>` | 本群播报文案 |
| `/刷屏 重置` | 清除本群覆盖，回退全局默认 |

## 播报文案占位符

`notify_template` 与 `/刷屏 提示` 支持以下占位符：

| 占位符 | 含义 |
|---|---|
| `{at}` | @触发者（作为消息组件，不在文本里） |
| `{user}` / `{nickname}` | 触发者昵称 |
| `{user_id}` | 触发者 QQ |
| `{group_id}` | 群号 |
| `{count}` | 窗口内实际消息条数 |
| `{window}` | 统计窗口（秒） |
| `{mute}` | 禁言秒数 |
| `{mute_text}` | 人类可读禁言时长（如「10 分钟」）；禁言失败时为「（禁言失败）」 |

默认模板：

```
{at} 你在 {window} 秒内发送了 {count} 条消息，达到阈值，已被禁言 {mute_text}。
```

示例自定义：

```
/刷屏 提示 {at} 刷屏太猛啦，先冷静 {mute_text} 🚫
```

## 触发逻辑

```
群消息事件
  ├─ 开关关 / 机器人自己 / 管理员豁免 / 白名单 → 忽略
  ├─ 冷却中 → 忽略
  ├─ 记录时间戳，弹出窗口外的旧记录
  └─ 记录数 ≥ 阈值 → 清空窗口 + 设置冷却 + 禁言 + 播报
```

## 平台支持

| 平台 | 禁言 | 说明 |
|---|---|---|
| `aiocqhttp`（OneBot v11 / NapCat 等） | ✅ | `event.bot.call_action("set_group_ban", ...)` |
| 其他平台 | ❌ | 未实现时仅计数 + 播报，日志会给出警告；可在 `_mute()` 中按平台扩展 |
